# PI AGENT 硬性约束与验收清单

本文件供用户与系统提示词共同加载。约束必须落成代码检查和测试；仅让模型阅读不能构成安全边界。下表任何必需项未通过，禁止将相应能力标为 VERIFIED 或建议发布。

## 数据与安全约束

| 编号 | 必须满足 | 最低验证证据 |
| --- | --- | --- |
| H01 | 公共突变体身份为稳定唯一 public_id；不从内部编号推导，不把数据库主键冒充业务编号 | 独立编号 fixture、唯一性/发布必填测试；核对内部编号来源 |
| H02 | 外部接口不以 internal_id 定位或返回私有身份；公开列表/详情/搜索/导出均执行公开发布边界 | 正向公开 ID 命中；现存与不存在内部 ID 的负向测试；私有/删除/未发布记录不泄漏 |
| H03 | 内部搜索必须经服务端内部权限授权，并限制数据范围 | 匿名、普通登录用户、两个不同内部权限范围交叉访问测试 |
| H04 | v4/v5 是不同命名空间；同名 accession 能共存并正确检索 | PostgreSQL 同名跨 assembly 数据、唯一约束和查询测试 |
| H05 | assembly 与 release 独立；不能固定活动 release 而让另一版本不可发现 | 两个 release 承载 v4/v5 的检索测试；请求与结果上下文一致 |
| H06 | 无版本查询不能静默隐藏其他版本；错误版本不能静默回落默认版本 | 多版本分组或明确消歧响应；未知/不匹配 assembly 测试 |
| H07 | 搜索、详情、表达、关联变异、序列、JBrowse 及缓存使用一致版本上下文 | 真实请求断言和浏览器全链路验证，不能只检查 URL 字符串 |
| H08 | 跨版本映射有来源、关系类型、源/目标 assembly；不按相似字符串猜测 | 一对一、一对多、多对一、无映射以及相似但无关系的反例 |
| H09 | 缓存和 cursor 绑定查询、过滤、站点、release、assembly；内部缓存按授权范围隔离或禁用 | 同 query 跨站点、用户权限、release、assembly 交叉请求；旧 cursor 拒绝或重置 |
| H10 | external/internal 构建、访问与私有内容缓存边界明确；noindex 不是鉴权 | 双构建、内部访问控制、private/no-store、CORS/origin、Service Worker 检查 |
| H11 | 泄漏扫描针对真实进入测试输入的合成保护值，包含响应、导出与外站制品 | fixture 输入证据、扫描正向检出自测、external 零泄漏结果；空扫描不是证据 |
| H12 | PostgreSQL 维持身份/关系/发布/权限权威；迁移保持引用和历史身份 | 迁移升级、回填校验、恢复路径、外键和导入/投影集成测试 |

公开编号与内部编号的碰撞规则必须在 T0 定义。不能通过“禁止所有数字查询”或“所有突变体都返回空结果”伪造 H01/H02 通过。
跨版本关联可以晚于独立版本搜索，但如果交付范围包含完整核心需求，H08 仍须完成；缺少真实映射数据时准确报告数据依赖。

## 工程硬约束

- 禁止删除/跳过失败测试、降低断言、扩大忽略规则、强制转换类型或吞掉错误来制造绿色结果。合法的测试更新须解释旧断言为何与批准契约冲突。
- 禁止仅凭 py_compile、TypeScript 语法解析、mock、SQL 文本匹配或扫描器自测宣称数据库/类型检查/E2E 已通过。
- 禁止手工修改 OpenAPI 或客户端生成物作为最终一致性方案；从权威接口重新生成并跑 contract 检查。
- 禁止以占位实现、TODO、硬编码成功响应、虚假统计或演示数据冒充完成的功能。
- 禁止并发改同一共享文件；禁止未经协调修改其他执行者的契约。禁止清空脏工作区或覆盖无关变更。
- 禁止读取或打印与任务无关的凭证。日志及交付记录不包含 token、密码、生产内部编号或未公开科研数据。
- 禁止对生产库运行测试 fixture、drop/create schema、回填或迁移。先核对隔离测试目标，无法确认时不执行数据修改。
- 禁止擅自生产发布、推送受保护分支、force push、reset --hard 或大范围删除。可逆的本地实现与隔离测试可在授权范围内自主执行。
- 不伪造工具可用性、命令输出、测试次数、截图、commit 或智能体结果。环境失败如实报告，修复后重验。

## 机器门禁接入要求

执行者 C 应将适用项接入现有 CI：PostgreSQL 集成与迁移测试 → OpenAPI/client 一致性 → lint/typecheck/unit → 双站构建与扫描 → 浏览器验收。
使用当前仓库真实脚本和工具版本；不得编造 CI job 已存在或已运行。测试连接信息由隔离测试环境提供，不写入文档。
各验收结果写入执行状态文档，并链接日志或报告。某门禁无法在当前环境执行时标记未运行，保留阻断状态。

## 完成判定

单任务 VERIFIED = 约定行为实现 + 相关正反例通过 + 调用方同步 + 当前版本证据可复现。
全量核心完成 = H01–H12 全部适用要求通过 + 客户端生成一致 + 类型检查/构建通过 + 实际 UI 全链路通过。
发布 = 全量验收通过后，另有用户明确发布授权。不得把这三种状态混用。
