# SoyMutDB Aegis Workspace

This workspace holds durable requirements, plans, baselines, and architecture records for SoyMutDB work. It is a process workspace only: it does not replace product documentation, API contracts, repository rules, or implementation owners.

## Entry points

- [INDEX.md](INDEX.md) lists registered Aegis records.
- [BASELINE-GOVERNANCE.md](BASELINE-GOVERNANCE.md) defines how requirement and architecture baselines are used.
- [baseline/](baseline/) contains dated evidence snapshots; snapshots do not independently authorize behavior.
- [plans/](plans/) contains approved, executable implementation plans.

Keep records scoped to durable decisions and resumability needs. Do not copy logs, full diffs, secrets, or generated build artifacts into this workspace. Register new records in `INDEX.md`; update an existing entry rather than duplicating it.
