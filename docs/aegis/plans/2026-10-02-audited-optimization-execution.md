## 2. 硬性约束（所有阶段适用）

| 编号 | 约束与判定 |
| --- | --- |
| H-01 | 保留起始工作树所有用户修改；冲突文件暂停该子任务并说明，其他独立任务可继续。未经明确指令不提交、不 amend、不推送、不发布。 |
| H-02 | 先读现行入口、基线、对应 ADR/plan，再沿真实入口与间接依赖查实现；文件名、注释、旧会话、历史数字均非现状证明。 |
| H-03 | 每包只有一个明确目标，写出允许修改路径、前置、验收、回滚；职责已存在时复用，不新造同一业务流程或复制门禁。 |
| H-04 | PostgreSQL 继续是身份、权限、关系、状态的权威；ClickHouse 为分析投影。表格、缓存、搜索索引不成为第二权威库。 |
| H-05 | public/internal 标识、assembly、release、站点变体及 keyset 分页契约保持。隔离改动须覆盖正向与泄漏负向矩阵，skip/xfail 不抵验收。 |
| H-06 | token 只驻模块内存，refresh 走 HttpOnly cookie；URL、前端存储、日志和文档不落凭据。保留 CSRF、单飞 refresh 与 unsafe mutation 不自动重放。 |
| H-07 | 公共浏览和公开联系表单保持匿名可用；只对需账户的操作设门禁。UI 隐藏不替代 API 鉴权；网络错误/5xx 与无登录、无权限分开呈现。 |
| H-08 | 禁止把未接线辅助模块的测试写成运行时保护；SSR 不共享用户态、账号切换不复用上个用户的个人缓存。 |
| H-09 | 运行实验只用命名的独立测试库/隔离样本；禁止终止未知数据库会话、重启共享服务、清库、修改主库参数或直接在主库建删索引。 |
| H-10 | 依赖 pin 与锁文件保持；新增依赖必须记录必要性、体积和治理结果。不为排除环境故障升级整个依赖图或用 skip 洗绿。 |
| H-11 | 新 API 为加法式并同步客户端生成与契约检测；数据库变更有升级、失败恢复与回退策略。每条引入的外部 API 给出官方来源、版本、作用域与错误契约。 |
| H-12 | outbox 与业务写入同事务；外部同步失败不回滚已提交业务。仅返回 False 的机器人 best-effort 不等于可靠表格同步。 |
| H-13 | UI 文案走 zh/en 资源，保留键对等；不扩大 baseline/白名单消除真实问题。a11y 验证键盘、焦点、名称、错误反馈，不能只数源码模式。 |
| H-14 | 对照先通过，消融只改一个因素，在实际调用路径观察，再恢复并复跑。变异导致导入/语法/环境失败不计“守卫杀死变异”。 |
| H-15 | 保存命令、真实退出码、前后快照与原始证据路径；管道使用 pipefail 或立即获取 PIPESTATUS，避免把 tail 的 0 当测试退出码。 |
| H-16 | 结论区分：源码确认、基线通过、变异被杀、组件行为、端到端、部署态。pass 数量不等于消融场景数；未跑项写明前置和原因。 |
| H-17 | 生产发布只消费同一轮已验证的不可变制品，不重构建；迁移、数据 release、前端/镜像 digest 与队列版本均纳入兼容与回退检查。 |
| H-18 | 明确违背隔离、产生数据损坏风险、出现身份泄漏或证据矛盾时停止对应阶段，回到最早不确定节点。不扩大探测范围来掩盖复现失败。 |

## 3. 分阶段施工与验收

### W0 · 重新建立基线（所有阶段前置）

画出发布入口、CI 两跳链、认证链、seed contact/outbox 链。现存未跟踪实验代码作为待审查输入，不静默删除，也不直接视作可靠基础。为每阶段声明风险、修改范围和架构复审必要性。

验收：得到一份新的基线记录，区分既存红灯、环境阻碍与本轮引入问题。没有可用浏览器或 Docker 时先标未验证，不继承旧会话的“无浏览器”判断。

### W1 · 交付阻断与守卫维护（依赖 W0）

核实 jbrowse Dockerfile 的失效 `packages/ui-vue` COPY，做最小修复；核查 `.umi*`/构建目录过滤与真实源码扫描。storage 规则允许明确的主题偏好 key，阻断认证 token 存储；仅按变量名称匹配 TOKEN/AUTH 不足以覆盖伪装 key，需真实负例。

扫描 TS/TSX 并保证存在真实消费者，空扫描不是 PASS。只跳过明确生成目录，不跳过业务层。沿已有 CI 编排复用门禁，不再次添加同一命令。

验收：COPY 守卫通过且缺源负例失败；已知生成目录噪声排除；主题偏好通过、认证 token 持久化负例失败；scripts 契约通过。Docker 可用时再构建镜像，缺前置时记镜像未验证。

回滚：仅撤销本包局部 diff，保留 W0 已记录的旧修改；不对整文件恢复 HEAD。

### W2 · assembly 工厂和作用域（依赖 W0；可与 W1 独立）

枚举当前全部目录消费者，不冻结历史“10 个”数量。统一通过查询工厂生成 key 与请求，至少携带 release，保持显式站点上下文。检查 `getReleaseId()`、请求 header 和 UI release 同源。

未 pin 的“活动 release”语义继续支持，定义发布成功后的目录失效与 reload 策略；用短 TTL 不能代替切换失效。`all()` 只作失效前缀。保留无效 assembly 深链显式失败，不回退默认基因组。

验收：release A/B 目录不同且缓存不串；站点键分离；活动 release 改变后重新获取；未知深链无查询；守卫覆盖实际消费者，注入直写 key/删除 release 后在真实查询路径翻转。

### W3 · 登录、权限与个人缓存（依赖 W0）

沿 `umi-entry → react-app → api-client/auth` 保留一个认证协调者。React provider/hook 用响应式状态接入 restore/login/logout 结果；对未跟踪 `session.ts` 明确复用、重构或待废弃结论，禁止只把布尔值接进 enabled 当作完成。

| 状态 | 行为 |
| --- | --- |
| restoring | 合并初始化 refresh，受限操作等待；公共页面可读，不闪现权限结果。 |
| anonymous | 不请求个人 me/通知/任务；显示登录入口且保留当前公共页。 |
| authenticated | 加载用户与能力；登录成功失效旧匿名结果，账号变更清空个人缓存。 |
| expired | 已建立会话失效后按页面性质提示重登，保留校验后的站内回跳；公共页不无条件强跳。 |
| error | 网络/5xx 展示可重试状态，保留可读公共内容，不伪装成 401/403。 |

401/403 的会话与授权含义分别处理，inactive/锁定账号按 API 契约处理。以服务端 grants 或新增的用户权限合同判断能力；新增端点先确认现存能力接口职责，不把公共 `/capabilities` 当用户授权。

BLAST/analyses 的创建和个人任务查询需登录与相应能力；公共基因/变异浏览及联系表单维持现有匿名契约。管理端保留现有 AuthProvider，只修角色能力、响应式状态与覆盖缺口，不另造 token store。

验收：真实 hook/入口的匿名零个人请求、restore 成功/失败、账号切换、登出、并发 401 单飞、无效回跳、viewer 403、所有 researcher-granted 角色、停用账号与网络故障。只删除某一门控后出现个人请求或错误跳转才计运行时 ACTIVE。

### W4 · 门户与管理端 UI/UX、功能接入（依赖 W0；鉴权行为依赖 W3）

复用现行 `2026-10-01-admin-pro-migration` A1–A6 与门户方案，按路由分包，不新建竞争计划。登记每页“路由/导航/endpoint/能力/读写目标/成功失败状态/证据”。管理端重点检查导入、发布、媒体、新闻、文献、settings、审批与真实指标，缺端点明确标缺口，零值 mock 不作真实接入。

运行三端 ant CLI lint/usage/token；记录门面/别名导致的扫描盲区。TSX AST 或组件运行验证补充多行 alt、适配器 rowKey、列表换序/翻页、键盘焦点与移动布局；门面范围由消费者需求决定，不强制平齐或 export 全部组件。

列表继续使用原分页合同，ProTable 包装不切回客户端全量分页。编辑表单验证双语、写入实例、引用阻断、失败恢复、权限与审计。新增会话测试替代已经丢失的覆盖，而非统计注释中是否出现 ABLATION。

验收：CLI 结果有覆盖说明；每个完成页面有真实读写接入证据；成功/空/加载/失败/权限状态可观察；键盘与窄屏验证；单变量修改在渲染/请求链翻转。只有源码扫描的条目标源码级，不宣称视觉通过。

### W5 · 企业微信机器人、智能表格、表单与文档搜索（依赖 W0；权限依赖 W3）

既有新申请/任务/release 机器人继续复用。先确认企业微信或腾讯文档的具体产品、官方 API、租户授权、服务账号、限流、SDK/版本与部署目标；Bitable 不是默认已确认接口名称。没有官方合同只做可测试适配接口和待核实记录。

公开表单与登录库存申请明确分表；外部身份按租户及来源域映射，审批动作进入本地服务授权/审计，不把表格直接修改当本地批准。

| 能力 | 必交付合同 |
| --- | --- |
| 智能表格同步 | 字段白名单与个人信息出站批准；事务 outbox；本地对象/远端记录映射；对象版本；重复及乱序处理；超时重试、死信、人工重放、定期对账。应用 API 写入不继承机器人丢弃失败语义。 |
| 表单接入 | 来源、字段验证、限额/限速、submission ID 去重、身份域、事务边界；保留现有公开表单，无账号提交不强制套 requester 外键。 |
| 入站回调 | 官方验签/解密参数与样例；校验失败、重放、重复、畸形消息、租户错配负例；密钥只注入接收服务，不与出站 webhook 共用。 |
| 文档搜索 | 精确检索域、账号/租户映射、逐文档 ACL、索引权限版本、删除/撤权传播、结果权限重验；公开搜索与企业文档隔离，无权限时标题/摘要也不泄漏。 |

外部调用不进公开请求关键路径；worker 路由按现存任务所有权设计。凭据脱敏、token 过期与并发刷新、限流退避、健康检查、停用、审计与数据保留均有测试。回调审批写操作默认不开放，先完成只读能力与本地审批深链。

验收：离线合同和负例通过，真实凭据验收另记；重复通知不增长、乱序不回写旧版本、失败业务提交不丢失、死信可重放、文档越权零泄漏。无凭据绝不写“接入已完成”。

### W6 · pgcli 数据库验证与迁移（依赖 W0；与 W1–W4 可独立）

使用最小数据集的独立副本。先核实迁移版本、表、约束、索引、`last_analyze/last_autoanalyze`、`pg_stats` 与统计重置情况；外键索引检查前导列、复合覆盖、有效标记与部分谓词。完整库导出含个人数据，需限定必要表、访问模式、保留期限并脱敏；不默认整库 dump。

两组先相同 ANALYZE，用真实 API 查询 SQL/参数与多种选择性。只改变一个索引，预热策略一致，A/B 交替至少五轮，记录完整 JSON 计划、根层 Execution Time、buffers、规划时间与结果一致性；报告中位数、范围、样本数及索引空间/写成本。样本收益与端到端收益分开。

收益成立后才设计 Alembic concurrent index 迁移、autocommit、部分失败/invalid index 清理、幂等与 downgrade。共享库配置、preload、重启不在本包自动操作范围。

验收：实验可重放、结果相同、因素可隔离；迁移升级/失败恢复/回退在独立 PostgreSQL 通过；未取得流量证据的索引与配置保持建议状态。

### W7 · 可回退的部署切换（依赖 W1–W4；启用企业微信时再依赖 W5）

先定义原子对象：门户双站、管理端、API、worker、数据库兼容版本与静态对象清单。数据 active_release 另有事务，不声称跨所有存储全局事务；通过候选部署、版本兼容和流量切换建立可见性边界。

按“构建不可变制品 → 校验 digest/manifest/配置 → expand 迁移 → 候选健康检查与 smoke → drain/兼容 worker → 流量切换 → 观察 → 延后 contract 清理”执行。Redis 队列 payload 需版本兼容，在途任务可完成或受控重试。

manifest 包含 Git SHA、各应用镜像/静态制品 digest、schema 版本、site variant、数据 release、配置引用、验证记录。发布器只消费验证器产物，不重建；默认保留旧制品与兼容 schema，失败优先切回旧流量，破坏性 down 不自动执行。

验收：候选健康失败、迁移失败、digest 不一致、切换中 worker 失败、静态资源缺失各有故障注入；旧服务持续可读；日志证明回退到上一组制品，恢复耗时和数据一致性实测。缺部署条件仅交付脚本与本地测试，不宣称原子发布通过。

## 4. 统一消融协议与完成门槛

场景表至少包含 ID、需求、实际入口、保护因素、对照输入/状态、变异差异、对照/变异真实 exit 与观测、恢复结果、证据层级。源文件变异优先放隔离临时树；如果必须临时改工作树，先备份当时内容，结束校验字节与 diff，保留原有脏改。

| 判定 | 门槛 |
| --- | --- |
| 基线通过 | 未做有效变异，只记录现状测试结果。 |
| GUARD-ACTIVE | 同输入下，中和一个真实保护因素后预期行为翻转，恢复后回到对照；标明函数/组件/E2E/部署层级。 |
| GUARD-INERT | 已证实变异进入真实执行路径，但保护性观测未翻转；排除冗余保护与测试输入不足后再解释。 |
| GAP | 对照失败、保护缺失或覆盖链缺口，单独区分产品故障和证据缺口。 |
| 未验证 | 语法/导入失败、变异未命中、缺环境/凭据、未跑；不计通过或 ACTIVE。 |

每包报告结果、关键 diff、验收数字、命令/exit、失败与未跑项、回滚位置、下一包前置；未闭环项保持待办，不修改基线配合漂移。并行仅用于读集或不相交写范围，公共 auth/查询工厂/协议层必须单一所有者。
