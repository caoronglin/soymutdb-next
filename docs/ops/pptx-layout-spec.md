> **状态**：本文由 QA（qa-acceptance）把 `docs/01.pptx`（7 页）的每页布局整理成**实现对照规范**，供
> `frontend-platform` 的 **t24（首页重构）/ t25（全站布局审计）** 对齐。规范**以 pptx 为准**描述**要实现的布局**，

> 本文为**前端对齐基准**，不作为数据面/功能正确性门禁（那仍属 G0–G16）。

## 0. 如何阅读 / 使用

- **每页一节**：`doc/01.pptx` 的第 N 张 slide ↔ 本规范的「§N 页面」。
- 每页给出：`意图 / 布局结构（区域 + 坐标，in） / 交互元素（输入/下拉/按钮）/ 数据语义 / 实现映射 / 开放项`。
- 尺寸：幻灯 10.83 × 7.5 in（4:3）。坐标以「左上角 x, 左上角 y」+ 宽高给出，供前端换算为容器/栅格布局。
- 术语：pptx 用 **“收索”**（应为“搜索”）、**“Gbrowse”**（代码库为 **JBrowse 2**）。规范在「术语对照」统一说明。
